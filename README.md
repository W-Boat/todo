# 交汇

Android 12+ 中文待办应用，基于 Jetpack Compose 和 [COUI-Kit](https://github.com/ItosEO/COUI-Kit)。

打开设置，填写支持 JSON 模式的 OpenAI 兼容 Chat Completions HTTPS 地址、模型和 API 密钥。模型接收当前输入和设备时间，返回结构化草稿。确认后才写入本地。接口和模型可以保存，密钥仅驻留当前页面会话。离线模式可解析常用中文时间和待办表达。

试着输入「下周二下午三点在会议室开会，提前二十分钟提醒，备注带设计稿，然后去驿站取快递」。识别后可修改标题、移除单项，再批量保存。去重使用归一化的主题、时间和地点。

通过简洁、日历、便签和流线视图查看待办。展开有时间的待办，可以把事件交给系统日历应用确认。

在设置里开启通知和精确提醒权限。有定时信息的事项默认通知，支持提前、震动、高优先级和实时倒计时。系统重启后重排未来提醒。准点权限关闭时使用非精确闹钟。提醒受渠道、勿扰、系统策略和设备状态影响。Android 16 及以上可以请求将倒计时提升为实时活动，最终展示由系统决定。

GitHub Actions 执行单元测试和 Debug APK 构建，APK 从 Actions 产物下载。
